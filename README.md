# Kobozo Bot downloads

Public installers and desktop downloads for [Kobozo Bot](https://kobozo.io).
The product source is maintained in a separate private repository. This repository
is a distribution channel, not an open-source release of the product.

[Download the latest preview](https://github.com/kobozo/kobozo-bot-releases/releases/latest).

The server installer supports Proxmox VE 9 on x86-64. It installs an orchestrator
LXC and opens a web setup wizard. The Mac client supports Intel and Apple Silicon
on macOS 13+. Preview Mac builds are not yet Apple-notarized.

Each release includes SHA256SUMS. Builds and checks run on Kobozo's own Linux and
Mac hardware. Downloads do not require an email address or registration.

For hosting, support and contact requests, visit [kobozo.io](https://kobozo.io/contact/).
