# Kobozo Bot how-to

Customer documentation for installing and using [Kobozo Bot](https://kobozo.io).
Product source stays private; this guide is published with each preview release in
[`kobozo/kobozo-bot-releases`](https://github.com/kobozo/kobozo-bot-releases).

Screenshots show the current demo or a safe lab installation. They are real
product captures, not mockups.

## Guides

1. [Install on Proxmox](install-proxmox.md) — download, orchestrator LXC and web setup
2. [Your first team](first-team.md) — bots, chat, Details and memory
3. [My workspace](my-workspace.md) — account, models, language and server settings
4. [Computers and desktops](computers.md) — bot desktops, handoffs and Teach
5. [Mac and phone](mac-and-phone.md) — native Mac client and installed web app
6. [Integrations and routines](integrations-and-routines.md) — MCP accounts, standard IMAP mailboxes and schedules
7. [Skills](skills.md) — methods for all bots, one project, or one bot
8. [Images and spoken audio](media.md) — per-bot image and speech-output providers, and the account Library
9. [Decision models](decision-models.md) — Jev and on-prem LAYA for fast, typed judgments

## Scope

This how-to describes released, tested behavior only. Limits and unfinished work
are stated explicitly. Internal lab runbooks and architecture notes are not part
of this public guide.
